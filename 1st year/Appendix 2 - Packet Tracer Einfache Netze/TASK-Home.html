    Cisco Packet Tracer: Einfaches Netzwerk erstellen

    Lernziele und Kompetenzen

    • die Packet-Tracer-Oberfläche bedienen
    • Netzwerktopologien erstellen
    • Endgeräte und Netzwerkkomponenten auswählen
    • Geräte umbenennen und dokumentieren
    • Kabeltypen korrekt auswählen
    • DHCP zur automatischen Adressvergabe nutzen
    • die Netzwerkkonnektivität testen
    • eine Packet-Tracer-Datei speichern und verwalten

    Voraussetzungen

    • Installierter Cisco Packet Tracer
    • Grundkenntnisse über IP-Adressen
    • Grundkenntnisse über Netzwerkgeräte

    Aufgabenbeschreibung

    In dieser Übung erstellst du ein einfaches Netzwerk vollständig von Grund auf. Dabei fügst du die benötigten Geräte hinzu, verbindest sie mit den passenden Kabeltypen, überprüfst die automatisch vergebenen IP-Adressen und testest die Kommunikation zwischen den Geräten. Abschließend speicherst du die Topologie als Packet-Tracer-Datei.

    Gerät Schnittstelle Adressierung
    PC Ethernet0 DHCP
    Wireless Router WRT300N LAN 192.168.0.1/24
    Wireless Router WRT300N Internet DHCP
    <INT>.com Server Ethernet0 208.67.220.220/24
    Laptop Wireless0 DHCP

    Teil 1 – Topologie erstellen

    Füge folgende Geräte in die Arbeitsfläche ein:

    End Devices

    • PC
    • Laptop
    • Server

    Network Devices

    • Wireless Router WRT300N

    WAN Emulation

    • Internet Cloud
    • Cable Modem

    Teil 2 – Geräte verkabeln

    Schritt 1 – PC mit Wireless Router verbinden

    Verwende: Copper Straight-Through

    PC FastEthernet0
↕
Wireless Router Ethernet 1

    Schritt 2 – Wireless Router mit Cable Modem verbinden

    Verwende: Copper Straight-Through

    WRT300N Internet-Port
↕
Cable Modem Port 1

    Schritt 3 – Cable Modem mit Internet Cloud verbinden

    Verwende: Coaxial Cable

    Cable Modem Coaxial
↕
Internet Cloud Coaxial

    Schritt 4 – Internet Cloud mit <INT>.com Server verbinden

    Verwende: Copper Straight-Through

    <INT>.com Server Ethernet0
↕
Internet Cloud Ethernet-Port

    Teil 3 – Wireless Router konfigurieren

    Öffne den WRT300N.

    Kontrolliere die LAN-Konfiguration:

    IP-Adresse: 192.168.0.1
Subnetzmaske: 255.255.255.0

    Der integrierte DHCP-Server soll aktiviert bleiben.

    DHCP prüfen

    Kontrolliere:

    DHCP Server = Enabled

    Startadresse:

    192.168.0.100

    oder Standardwert des Geräts.

    WLAN konfigurieren

    Öffne:

    GUI → Wireless

    Vergib folgende SSID:

    Netzwerkname: PacketTracer-WLAN

    WLAN absichern

    Öffne:

    Wireless Security

    Konfiguriere:

    Security Mode: WPA2 Personal
Passphrase: <KN>_123!

    Dokumentiere die Einstellungen.

    Teil 4 – Internet Cloud konfigurieren

    Die Internet Cloud simuliert in dieser Übung den Internet Service Provider (ISP). Sie verbindet das Kabelnetz des Cable Modems mit dem Ethernet-Netz, in dem sich der <INT>.com Server befindet.

    Bevor die Internet Cloud konfiguriert werden kann, müssen die erforderlichen Schnittstellenmodule vorhanden sein.

    1. Öffne die Internet Cloud.
    2. Wechsle zum Reiter: 
    Physical

    Kontrolliere, ob folgende Module installiert sind:

    PT-CLOUD-NM-1CX

    (Coaxial-Anschluss für das Cable Modem)

    und

    PT-CLOUD-NM-1CFE

    (Ethernet-Anschluss für die Verbindung zum Server)

    Falls eines oder beide Module fehlen:

    1. Schalte die Internet Cloud aus, indem du auf den Netzschalter klickst.
    2. Ziehe das benötigte Modul aus dem Modulbereich auf einen freien Steckplatz der Cloud.

    Erst danach können die Verbindungen aus Teil 2 und die Konfiguration aus Teil 4 erfolgreich durchgeführt werden.

    Wechsle zu:

    Config

    Aktiviere die benötigten Schnittstellen.

    Die Nummerierung kann je nach PT Version abweichen: Verbinde die tatsächlich verwendeten Coax- und Ethernet-Ports der Cloud.

    Wähle die Schnittstelle:

    Coaxial

    Kontrolliere:

    Port Status: On

    Diese Schnittstelle verbindet das Cable Modem mit dem Providernetz.

    Wähle:

    Ethernet

    Kontrolliere:

    Port Status: On

    Diese Schnittstelle verbindet das Providernetz mit dem <INT>.com Server.

    Die Internet Cloud muss wissen, welcher Verbindungstyp auf der Ethernet-Schnittstelle verwendet wird.

    Wähle unter INTERFACE die Schnittstelle:

    Ethernet6

    Suche im Konfigurationsfenster die Einstellung: Provider Network und wähle als Provider-Typ:

    Cable

    Wechsle innerhalb der Cloud zu:

    Config → Connections

    Verbinde:

    Coax7 ↔ Ethernet6

    Dadurch werden Datenpakete zwischen dem Kabelnetz und dem Ethernet-Netz weitergeleitet. Ohne diese Zuordnung kann das Cable Modem den Server nicht erreichen.

    Nach erfolgreicher Konfiguration sollte folgende Kette bestehen:

    PC → Wireless Router → Cable Modem → Internet Cloud → <INT>.com Server

    Alle Verbindungen müssen grün angezeigt werden.

    Beantworte folgende Fragen:

    1. Welche Funktion übernimmt die Internet Cloud in dieser Topologie?
    2. Warum werden innerhalb der Cloud unterschiedliche Medientypen (Coax und Ethernet) verwendet?
    3. Welche Geräte wären ohne die Zuordnung von Coax und Ethernet nicht erreichbar?
    4. Welche Rolle übernimmt die Cloud im Vergleich zu einem realen Internet Service Provider?

    Teil 5 – <INT>.com Server konfigurieren

    Der Server ist nicht nur die Webseite, sondern auch DHCP- und DNS-Dienste auf der WAN-Seite. Der Router erhält seine Internet-Adresse per DHCP vom Server-Netz und die Namensauflösung für <INT>.com erfolgt über den DNS-Dienst des Servers

    Öffne den Server.

    IP-Konfiguration

    Öffne:

    Config → FastEthernet0

    Konfiguriere:

    IP-Adresse: 208.67.220.220
Subnetzmaske: 255.255.255.0

    Öffne:

    Config → Global

    Konfiguriere:

    Gateway: 208.67.220.1
DNS Server: 208.67.220.220

    Dienste aktivieren

    Öffne:

    Services

    Aktiviere den Dienst:

    DHCP Service: On

    Erstelle einen DHCP-Pool für die Internet-Seite.

    Beispiel:

    Pool Name: WAN
Default Gateway: 208.67.220.220
DNS Server: 208.67.220.220
Start IP Address: 208.67.220.10
Subnet Mask: 255.255.255.0
Maximum Number of Users: 50

    Beantworte:

    1. Welches Gerät erhält später eine Adresse aus diesem Pool?
    2. Warum wird auf der WAN-Seite ebenfalls DHCP verwendet?
    3. Welche Informationen liefert ein DHCP-Server außer der IP-Adresse?

    Aktiviere:

    DNS Service: On

    Erstelle folgenden DNS-Eintrag:

    Name: <INT>.com
Address: 208.67.220.220

    Name: www.<INT>.com
Address: 208.67.220.220

    Beantworte:

    1. Welche Aufgabe erfüllt DNS?

    2. Warum ist eine IP-Adresse für Menschen schwieriger zu verwenden als ein Hostname?

    3. Welche Verbindung besteht zwischen DNS und dem Webbrowser?

    Aktiviere:

    HTTP: On

    Nach Aktivierung:

    Passe die Startseite an und füge deinen Namen ein.

    Beantworte:

    • Welche Aufgabe hat der HTTP-Dienst?

    Teil 6 – WAN-Adresse des Routers überprüfen

    Warte ca. 30 Sekunden oder verwende Fast Forward Time, damit der Router eine WAN-Adresse via DHCP beziehen kann.

    Nachdem der Server als DHCP-Server konfiguriert wurde:

    1. Öffne den WRT300N.
    2. Wechsel zu:

    GUI → Setup

    1. Kontrolliere den Internet-Port.

    Dieser sollte seine WAN-Adresse automatisch vom DHCP-Dienst des <INT>.com Servers beziehen.

    Beispiel:

    Internet IP Address: 208.67.220.x
Subnet Mask: 255.255.255.0
DNS Server: 208.67.220.220

    Beantworte:

    1. Von welchem Gerät wurde die WAN-Adresse bezogen?
    2. Welche DNS-Adresse wurde zugewiesen?
    3. Warum benötigt der Router einen DNS-Server?

    Teil 7 – Verbindung testen

    Öffne auf dem PC:

    Desktop → Command Prompt

    ping 192.168.0.1
ping 208.67.220.220

    Beantworte:

    1. Ist der Router erreichbar?
    2. Ist der Server erreichbar?
    3. Welche Route wird verwendet?

    Teil 8 – DNS testen

    Öffne auf dem PC:

    Desktop → Command Prompt

    ping <INT>.com

    oder

    ping www.<INT>.com

    Beantworte:

    1. Wurde der Hostname erfolgreich aufgelöst?
    2. Welche IP-Adresse wurde zurückgegeben?
    3. Welcher Dienst war für die Namensauflösung verantwortlich?

    Teil 9 – Laptop mit WLAN verbinden

    Öffne den Laptop.

    Navigiere zu:

    Desktop → PC Wireless

    Suche verfügbare Netzwerke.

    Verbinde den Laptop mit:

    PacketTracer-WLAN

    Authentifizierung:

    <KN>_123!

    Nach erfolgreicher Verbindung sollte der Laptop automatisch eine DHCP-Adresse erhalten.

    Teil 10 – DHCP auf PC und Laptop überprüfen

    Falls keine gültige IP-Adresse angezeigt wird oder Änderungen an der DHCP-Konfiguration vorgenommen wurden, kann die Adresse manuell neu angefordert werden.

    Desktop → Command Prompt

    Gib auf dem PC ein:

    ipconfig /release

    Fordere anschließend eine neue Adresse an:

    ipconfig /renew

    Prüfe die erhaltenen Werte:

    ipconfig /all

    Falls der Laptop bereits mit dem WLAN verbunden ist führe die gleichen Schritte durch.

    Hinweis: Nach Änderungen an DHCP-Pools, DNS-Einstellungen, Wireless-Router-Konfiguration sollte häufig ein

    ipconfig /release
ipconfig /renew

    durchgeführt werden, damit die Geräte die aktuellen Netzwerkeinstellungen erhalten.

    Dokumentiere:

    • IP-Adresse
    • Subnetzmaske
    • Default Gateway
    • DHCP-Server

    Analyse

    1. Welche Adressen wurden vergeben?
    2. Welches Gerät vergibt die Adressen?
    3. Welche Aufgabe erfüllt DHCP?

    Teil 11 – Webserver testen

    Öffne auf dem PC:

    Desktop → Web Browser

    Rufe auf:

    208.67.220.220

    Rufe nun nicht die IP-Adresse auf, sondern:

    http://<INT>.com

    oder

    http://www.<INT>.com

    Analyse

    1. Welche Protokolle werden verwendet?
    2. Welche Geräte werden durchlaufen?
    3. Welche Rolle haben Router, Cable Modem und Internet Cloud?

    Teil 12 – Reflexion

    Beschreibe den vollständigen Ablauf in einem Sequenzdiagramm:

    1. DHCP Discover / DHCP Offer / DHCP Request / DHCP Acknowledge
    2. ARP Request / ARP Reply
    3. DNS Query / DNS Response
    4. TCP Connection Setup
    5. HTTP Request / HTTP Response
    6. Webseite wird angezeigt
